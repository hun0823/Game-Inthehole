# Texture maps — quality trial

Baked equirectangular maps for four balls and four planets. The game still
falls back to the old canvas materials if a file fails to load.

## Reproduce

```bash
python3 tools/bake_sphere_maps.py
```

Requires Python 3, NumPy, and Pillow. Output is `assets/textures/*.webp`.

| Set | Size | Maps |
|-----|------|------|
| Balls (baseball, tennis, melon, oak) | 512×256 | albedo, normal, roughness |
| Planets (wood, desert, ocean, lava) | 1024×512 | albedo, normal, roughness; lava also emissive |

North pole is the top row, matching Three.js `SphereGeometry` with `texture.flipY = true`.
Patterns are evaluated in 3D on the sphere, so the longitude seam is the same point
on both edges. High-frequency normals fade out toward the poles. Watermelon stripes
run pole to pole and blend into a stem cap before they pinch. Oak end-grain rings
at the poles are the turned-wood end, not a UV smear.

## Source and license

These images are original procedural textures generated by
`tools/bake_sphere_maps.py`. No third-party texture files are shipped.
The studio environment is an original scene in `js/studioLight.js`, convolved
with Three.js `PMREMGenerator` (Three.js itself is MIT).

## What each map is

- **Baseball.** Warm white leather, a red figure-8 seam, and separated stitches. The normal map raises the stitches. Roughness is lower on the thread so the studio reflection catches it.
- **Tennis.** Optic yellow felt with a soft nap in the normal map, and one white curved band.
- **Watermelon.** Dark green and yellow-green stripes, irregular from pole to pole, with a brown stem cap.
- **Oak.** Long grain around the equator, growth rings at the poles, a side knot.
- **Wood planet.** Forest masses and lighter meadow, low hills in the normal.
- **Desert.** Sand dunes. Crests are lighter; the normal map carries the ridges.
- **Ocean.** Deep water, shallows, and islands with sandy coasts. Water roughness is low so the environment reflects.
- **Lava.** Cooled rock plates and thin cracks. The emissive map is only the cracks.

## Lighting and bloom

`js/studioLight.js` builds one PMREM from a gray room and a few soft panels, shared
by the board, the constellation, and the asset sheet. The renderer uses ACES Filmic
and the existing PCF soft shadows.

Bloom (`js/bloom.js`) is an additive half-resolution blur on the brightest pixels.
Auto mode (`js/quality.js`) enables it only when the device is not a phone, not
iOS, has at least 6 cores, and has no `deviceMemory` under 6. iPhone 60fps was
not measured, so auto leaves glow off there. Settings → Glow can force it on.
If a running playfield averages slower than about 54fps, glow turns off for that
visit. Gaps of 400ms or more are ignored so a stalled tab does not count as one
slow frame. The additive pass keeps the canvas alpha, so the starfield behind
the board stays visible.

The mapped planets' atmosphere is a thin fresnel shell. Its color is
premultiplied, so the rim stays faint instead of painting a solid halo. The
legacy shell used on the "before" shots is unchanged.

## Goals, as a set

The stock mint hole is unchanged. These four equipped goals were nudged so they
belong to the new ball:

- **Oak knot** is a deeper timber (`#a86a32`) so it matches the baked oak, not a generic orange ring.
- **Home plate** stays white. A thin red bar repeats the stitch color.
- **Tennis cup** is optic yellow, with a white lip, because a white cup read as a golf hole next to the yellow ball.
- **Watermelon** rind uses the stripe green (`#127338`). The cut face is watermelon red instead of the candy pink shared with the gummy dish.
